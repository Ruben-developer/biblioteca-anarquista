### Cambios (commit 0e8ac7e)
- `ContactView.jsx`: se elimina el `mailto:` como vía principal. El formulario
  hace `fetch POST` a `FORM_ENDPOINT = 'https://formsubmit.co/ajax/antarquia@riseup.net'`
  (FormSubmit, el servicio de formularios estándar para webs estáticas; sin
  registro previo — el primer envío dispara un correo de activación a
  `antarquia@riseup.net`). Campos `nombre_o_apodo` (Anónimo si vacío),
  `correo` ('no proporcionado' si vacío), `mensaje` (obligatorio: botón
  deshabilitado sin mensaje). Estados `idle|sending|success|error` con UI en
  la página: spinner «Enviando…», confirmación (incluye el correo si se dejó),
  y en error el correo directo `mailto:antarquia@riseup.net` como alternativa
  + botón «Reintentar». El endpoint es una constante exportada (migrar a
  Web3Forms/Formspree = cambiar una línea).
- `ContactView.test.jsx`: reescrito (6 tests): render con opcionales/obligatorio,
  no envía sin mensaje, envío con solo mensaje (fetch simulado: endpoint,
  POST, payload con Anónimo), envío con apodo+correo, error mostrando el
  correo directo, y «Enviar otro mensaje» tras éxito.
- Nota UX: se mantiene un enlace `mailto:` solo como fallback dentro del
  mensaje de error, nunca como flujo principal.
